Recommended: Resend API (works on Railway / Render / Fly.io)

Direct SMTP is often blocked on PaaS platforms. Resend uses HTTPS (port 443) which is never blocked.

  1. Sign up free at resend.com (3,000 emails/month free).
  2. Create an API key in the Resend dashboard.
  3. Add Railway variable: RESEND_API_KEY=re_xxxxxxxxxxxx
  4. Add Railway variable: NOTIFY_ADMIN_EMAIL=your@email.com
  5. Optionally add MAIL_SENDER=Lab Booking <you@yourdomain.com> (requires verified domain in Resend). Without it, the from address is onboarding@resend.dev.

Alternative: Gmail SMTP (only works if SMTP port 587 is open)

  1. Enable 2-Step Verification on your Google account.
  2. Go to Google Account → Security → App passwords and create an App Password.
  3. Set: MAIL_SERVER=smtp.gmail.com, MAIL_PORT=587, MAIL_USE_TLS=1
  4. Set MAIL_USERNAME=your@gmail.com and MAIL_PASSWORD=<App Password> (16-char code, not your login password).
  5. Set NOTIFY_ADMIN_EMAIL=your@email.com
