Option A — SendGrid (recommended for Railway)

Railway's IPs may be blocked by Cloudflare. SendGrid uses Twilio infrastructure and works reliably on Railway.

  1. Sign up free at sendgrid.com (100 emails/day, no expiry).
  2. Go to Settings → Sender Authentication and verify a single sender email address (no domain needed).
  3. Go to Settings → API Keys → Create API Key (Mail Send permission).
  4. Add Railway variables:
    • SENDGRID_API_KEY=SG.xxxxxxxxxxxx
    • MAIL_SENDER=Your Name <verified@youremail.com> (must match the verified sender)
    • NOTIFY_ADMIN_EMAIL=admin@youremail.com

Option B — Resend (may be blocked on Railway)

Resend uses Cloudflare. Some Railway deployments get error 1010 (IP blocked by Cloudflare firewall). Try SendGrid first.

  1. Sign up free at resend.com (3,000 emails/month).
  2. Create an API key → set RESEND_API_KEY=re_xxxx.
  3. Set NOTIFY_ADMIN_EMAIL to the email you registered with (free plan restriction).
