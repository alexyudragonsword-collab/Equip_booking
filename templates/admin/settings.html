Gmail setup

  1. Enable 2-Step Verification on your Google account.
  2. Go to Google Account → Security → App passwords and create an App Password.
  3. Set MAIL_SERVER=smtp.gmail.com, MAIL_PORT=587, MAIL_USE_TLS=1.
  4. Set MAIL_USERNAME to your Gmail address and MAIL_PASSWORD to the App Password (not your login password).
  5. Set NOTIFY_ADMIN_EMAIL to the address that should receive notifications.
